# Artist Manager — Design Context

## Purpose

A working tool for Songfinch creative production to quickly scan what artists on the roster have going on — recent releases, current tours, festival appearances, creative status — without spreadsheet duty. Used before campaign planning to decide who to prioritize.

## Audience

- Primary: Greg (Songfinch Head of Creative Production) and creative team
- Secondary: A&R, marketing leads doing pre-campaign research
- All are power users — comfortable with dense interfaces, value speed over hand-holding

## Personality (3 words)

**BOLD · UTILITARIAN · EDITORIAL**

- Bold = Big Shoulders display type, saturated color, confident contrast
- Utilitarian = information density, no decorative flourishes, every pixel earns its place
- Editorial = italic serif for human-written summaries, mono caps for system labels — it reads like a magazine masthead crossed with a developer tool

## Aesthetic Direction

- **Inspiration reference**: Songfinch internship "Four Lanes" deck — typography + palette only, NOT the magazine-spread layout
- **Closest analogue**: Linear (density + keyboard-friendliness) or Vercel dashboard (info-rich, warm-toned) — but with stronger typographic point of view
- **Anti-reference**: generic SaaS dashboard built on Tailwind defaults (gray-50/900, sans body, neutral). Also: landing-page hero/CTA patterns. This is a workbench, not a sales page.

## Visual System

- **Background**: cream `#F4EFE6` (warm, distinct from white/gray SaaS)
- **Ink**: `#0A0A0A` for text and borders
- **Signal palette** (used as accents/indicators, NOT as full-block backgrounds in normal views):
  - `--color-red: #F23222` → active touring / recent release
  - `--color-blue: #1E2DDB` → upcoming release
  - `--color-lime: #C9F33A` → industry writer / behind-the-scenes
  - `--color-ink` → quiet / between cycles
- **Type**:
  - `Big Shoulders` (display) — titles, artist names, big numerals
  - `Lora Italic` (serif italic) — summaries, editorial blurbs, human-voice copy
  - `JetBrains Mono` (mono, all-caps, tracked) — system labels, status, IDs, counts
  - `Inter` (sans) — body, buttons, form fields
- **Spacing**: tight by SaaS standards. Rows are compact (~56-72px), borders are hairline (1px ink/10).
- **Motion**: minimal. Use animation only for status state changes (pulse dot, shimmer for loading rows). No decorative hover transforms.

## Layout DNA

- **Persistent toolbar** at top (logo + actions), NOT a hero
- **List/row-based** artist views, NOT stacked color-block cards
- **Color as signal**, not as decoration — colored 8px dot or border-left strip indicates artist status
- **Empty state** = upload zone, not a marketing pitch
- **Detail expand inline** on row click (or right-side drawer if scope grows)

## Constraints

- Stack: Next.js 16 (App Router) + Tailwind 4 + TS + pnpm
- Fonts: already loaded via `next/font/google`
- Accessibility: WCAG AA contrast minimum, keyboard navigation for row selection and toolbar actions
- Performance: streaming NDJSON results from API, optimistic UI for queued rows

## Don't

- Don't render artists as full-bleed colored cards in the main list view (reserve that for a marketing landing if we ever build one)
- Don't add stock SaaS UI (gray cards, drop shadows, blue links, "Generated by..." footers)
- Don't introduce a 5th color or decorative gradient — the 4-color signal palette is the system
- Don't write copy in a "friendly product" voice — it should read like a producer's notebook
